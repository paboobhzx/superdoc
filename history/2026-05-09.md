  supports auto language detection, outputs SRT natively
- Amazon Translate for text translation — synchronous, cheap ($15/M chars)
- FFmpeg binary downloaded from S3 to /tmp on cold start (FFMPEG_LAYER_S3_KEY pattern)
- Video jobs use existing /jobs SQS flow — no new API Gateway routes needed
- output_keys (dict) is backwards-compatible alongside output_key (string)
- Separate /video route (not integrated into Home flow) per user preference
